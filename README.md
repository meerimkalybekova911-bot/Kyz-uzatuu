# Даткайымдын кыз узатуусу — интерактивдүү чакыруу сайты

Үч файлдан турат: `index.html`, `style.css`, `script.js`. Сүрөттөр `images/` папкасына, музыка тамыр папкага коюлат.

## 1. Маалыматты өзгөртүү (эң маанилүү бөлүм)

`script.js` файлынын эң башында `invitationData` объектиси турат — бардык окуя маалыматы ушул жерден өзгөртүлөт:

```js
const invitationData = {
  date: "2026-12-20",          // ← сана: ЖЫЛ-АЙ-КҮН
  time: "17:00",                 // ← саат: 24-саат форматында, countdown ушуга эсептейт
  displayDate: "20-декабрь, 2026-жыл",   // ← коноктор көргөн сана
  displayTime: "17:00",                   // ← коноктор көргөн саат
  venue: "«Асман Пэлас» той толгону",     // ← той өтүүчү жайдын аты
  address: "Бишкек шаары, Чүй проспекти 123", // ← толук дарек
  mapLink: "https://maps.google.com/?q=Bishkek", // ← Google Maps шилтемеси
  music: "music.mp3",           // ← музыка файлынын аты
  program: [                    // ← программанын тизмеси, каалагандай өзгөртсө болот
    { time: "18:00", label: "Конокторду тосуп алуу" },
    ...
  ],
};
```

Ошол эле файлда, бир аз ылдыйда, сүрөттөрдүн тизмеси турат:

```js
const galleryImages = [
  "images/photo1.jpg",
  "images/photo2.jpg",
  ...
];
```

## 2. Сүрөттөрдү кошуу

`images/` папкасына өзүңүздүн сүрөттөрдү коюңуз жана алардын атын so `galleryImages` тизмесиндеги аттарга дал келтириңиз (мисалы `photo1.jpg`). Сүрөт табылбай калса, ордуна көркөм алтын рамка-плейсхолдер көрүнөт — сайт эч качан бузулбайт.

Каалаган сандагы сүрөт кошсоңуз болот (6–12 сунушталат) — `galleryImages` тизмесине жаңы саптарды кошуп, `images/` папкасына сүрөттөрдү коюу жетиштүү.

## 3. Музыканы кошуу

Каалаган mp3 файлды долбоордун түпкү папкасына `music.mp3` деп коюңуз (же `invitationData.music` талаасында башка атты көрсөтүңүз). Музыка автоматтык түрдө ойнобойт — коноктор баскычты (♫) басканда гана башталат, бул мобилдик браузерлердин талабы.

## 4. Локалдуу текшерүү

Файлдарды түз браузерде ачуу кээ бир функцияларды (fetch, module) чектеши мүмкүн, ошондуктан жергиликтүү серверди иштетүү сунушталат:

```bash
cd папканын-аты
python3 -m http.server 8000
```

Андан кийин браузерде `http://localhost:8000` ачыңыз.

## 5. Акысыз жайгаштыруу (deploy)

Эң жөнөкөй жолдор:

- **Netlify Drop** (netlify.com/drop) — папканы сүйрөп таштаңыз, бир нече секундда шилтеме даяр болот.
- **Vercel** (vercel.com) — GitHub аркылуу же CLI менен `vercel` буйругу.
- **GitHub Pages** — папканы GitHub репозиторийине жүктөп, Settings → Pages бөлүмүндө иштетиңиз.
- **Cloudflare Pages** — GitHub репозиторийин туташтырып, автоматтык deploy.

Даяр болгон шилтемени WhatsApp аркылуу жөнөтсөңүз болот.

## 6. Техникалык эскертүү

- Эшиктин ачылышы CSS 3D transform менен жасалган (`perspective` + `rotateY`) — бул ыкма телефондордо эң ишенимдүү жана тез иштейт, ошондуктан татаал WebGL 3D модель ордуна тандалды.
- Фондо Three.js (CDN аркылуу) чыныгы 3D мейкиндикте жайылган алтын чаң бөлүкчөлөрүн жаратат, камера жай айланат — терең параллакс эффектиси үчүн.
- Күчсүз түзмөктөрдө (`navigator.hardwareConcurrency`, `deviceMemory` текшерилет) бөлүкчөлөрдүн саны автоматтык түрдө азаят, ал эми `prefers-reduced-motion` качкан колдонуучуларда 3D-бөлүкчөлөр такыр өчүрүлөт.
- RSVP жооптору азырынча `localStorage`га сакталат. Чыныгы базага туташтыруу үчүн `script.js` ичиндеги `initRSVP()` функциясында `fetch(...)` мисалы даяр — сервериңиздин дарегин коюп, комментарийди алып салсаңыз жетиштүү.
